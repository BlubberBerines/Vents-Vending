# Maintenance Underpass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A crowbar-pried floor grate in the Long Crawl that drops the player one-way into a drone-patrolled maintenance corridor, which leads upright to an inside-only exit door in the plaza.

**Architecture:**
- Security gets two pure-rule extensions, *trespass* and *hidden*, plus trigger volumes (`SecurityZone`) that `PlayerExposure` tracks.
- A catch inside a restricted zone escorts the player to that zone's exit point.
- Drones learn a floor height so they can patrol below y 0.
- The grate and exit use the existing `TunnelState` switch and `LatchDoor` patterns.
- The crowbar is an ordinary `ItemDefinition`: found as a once-only pickup, or bought through a pure `SupplyShop` from a new Supplies view on the VentNet PC.
- All geometry is generated by a new builder partial.

**Tech Stack:** Unity 6.3 LTS, URP, C# (assembly `VentsAndVending`), Unity Test Framework (EditMode), Input System, NavMesh (AI Navigation), Unity MCP for compile, test and play verification.

**Spec:** `Docs/superpowers/specs/2026-11-08-maintenance-underpass-design.md`

- Scenes are generated: after builder changes run `PrototypeSceneBuilder.BuildAllScenes()` via MCP `script-execute`. Before entering Play mode, back up `persistentDataPath/Saves`, and restore it after exiting.

  - crowbar price **60 CC**
  - pry time **≈1.2 s**
  - drop **≈3.6 m** (corridor floor y −3.6, ceiling ≈ −0.6)
  - corridor ≈3 m wide × 3 m tall, ≈28–35 m long, **6–8 side doors**, 2–3 open and dressed
  - **two drones**
- Exact copy from the spec:
  - grate without crowbar: *"Rusted solid. You'd need something to lever it."*
  - grate with crowbar: prompt *"Pry open grate"*
  - delivery: *"Package dropped in your locker."*

  - escort: *"Escorted off the premises."*
- The crowbar is **not contraband**, max stack 1, `ItemCategory.Equipment`.
- Plaza drones must behave exactly as today (floor 0).
- No save version bump: new state goes in `TunnelState` switches.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Exclude the root docx when staging.

## Review Focus

1. **Loading a save made after prying or picking up the crowbar.** The grate is open and the stash crowbar stays gone. Test: Task 4 Step 5 and Task 7 Step 6 (play: pick up / pry → save → reload).
2. **Being caught while carrying nothing, inside the underpass.** You're fined and escorted out, never caught twice in a row. Test: Task 2 Step 1 (`Escort_OnlyWhenRestrictedAndHasExit`) plus Task 8 Step 2.
3. **A drone parked under the closed grate.** It can't notice or chase a player in the gallery above (the closed grate collider blocks line of sight; the drone's zone is underground). Test: Task 8 play check from the gallery with contraband in pockets.
4. **Buying the crowbar with too little money or a full locker.** Nothing is charged and nothing is added. Test: Task 5 Step 1.
5. **Walking up to the exit door from the plaza side.** It's locked from that side and stays closed after use, so the underpass is never an entrance. Test: Task 7 Step 7.
